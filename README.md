# Fake Twitter/X Profile Detection

A machine learning web application that classifies Twitter/X accounts as **real** or **fake** using public account metadata. Built with scikit-learn and Streamlit.

## Features

- **Random Forest classifier** trained on 2,818 labelled profiles (1,481 real + 1,337 fake)
- **7 metadata features**: tweet count, followers, following, likes, listed count, URL presence, time-zone presence
- **Interactive Streamlit UI** with prediction form, model metrics dashboard, and feature importance chart
- **Secure local auth** — passwords hashed with PBKDF2-SHA256 (200,000 iterations + random salt)
- **Probability output** — shows likelihood (0–100%) with risk-level colour coding

## Dataset

| | Count |
|---|---|
| Real profiles | 1,481 |
| Fake profiles | 1,337 |
| **Total** | **2,818** |

Labels: `0 = real`, `1 = fake`

## Quick Start (Windows)

```bat
py -3.12 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python model.py
streamlit run fake.py
```

1. Run `python model.py` — trains the model and saves it to `artifacts/`
2. Run `streamlit run fake.py` — opens the web app at `http://localhost:8501`
3. Create an account, sign in, and enter public profile statistics

## Model Details

- **Algorithm**: Random Forest (300 trees, balanced class weights, min_samples_leaf=2)
- **Preprocessing**: SimpleImputer (median strategy) in a scikit-learn Pipeline
- **Split**: 75% train / 25% test, stratified, `random_state=42`
- **Metrics**: Accuracy, Precision, Recall, F1, ROC-AUC, Confusion Matrix

## Limitations

- Historical dataset (~2015) — may not reflect current fake-account patterns
- Metadata-only — does not analyse tweet text, images, or follower graphs
- Screening tool — not evidence to accuse, report, or ban anyone
